# Фаза 2 — Распределение работы

**Статус:** **модель распределения согласована командой 02.11.2026**; фактическое выполнение задач Фазы 3 учитывается отдельно.

## Цель

Распределить задачи Фазы 3 между четырьмя участниками с учётом предпочтений и ограничения по времени. Задания Фаз 2 и 3 связаны: сначала определён состав работ Фазы 3, затем решена задача распределения.

## Задача оптимизации

- 12 задач Фазы 3; суммарная трудоёмкость **138 человеко-часов**.
- Участники: Владислав, Виталий, Елена, Антон.
- Предпочтения по шкале 1–5; оценки часов из учебного модельного набора подтверждены командой 02.11.2026; независимые первичные анкеты не заявляются.
- Бинарная переменная `x[i,j]`: назначение задачи i участнику j.
- Цель: максимизировать сумму предпочтений `Σ p[i,j] × x[i,j]`.
- Ограничения: каждая задача одному исполнителю; лимиты по часам `40/36/32/40`; каждый получает минимум две задачи.
- Решение получено инструментом `scipy.optimize.milp` (HiGHS), а не произвольным выбором исполнителей.
