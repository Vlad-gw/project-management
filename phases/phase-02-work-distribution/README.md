# Фаза 2 — Распределение работы

![Статус](https://img.shields.io/badge/Статус-ожидает-lightgrey)

## Цель

Декомпозировать работы Фазы 3, оценить сложность/трудозатраты задач, собрать индивидуальные предпочтения участников и решить задачу распределения работ с учётом ограничений.

## Планируемые материалы

- декомпозиция Фазы 3;
- экспертные оценки трудозатрат;
- оценки предпочтительности задач;
- постановка оптимизационной задачи;
- решение и обоснование распределения;
- обновлённая RACI.
