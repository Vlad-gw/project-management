# Фаза 2 — Распределение работы

**Статус:** расчёты выполнены, результаты согласованы командой.  
**Период учёта:** 20.10.2026–03.11.2026.  
**Проект:** система аренды автомобилей.

## Цель

Распределить задачи подготовки Фазы 3 между четырьмя участниками команды с учётом трудоёмкости, индивидуальных предпочтений и ограничений по времени.

## Исходные данные

| Параметр | Значение |
|---|---|
| Количество задач | **12** (T01–T12) |
| Количество участников | **4** |
| Плановая трудоёмкость | **138 чел.-ч** |
| Шкала предпочтений | **1–5** |
| Лимиты времени (Владислав / Виталий / Елена / Антон) | **40 / 36 / 32 / 40 ч** |

Оценки и предпочтения согласованы командой 02.11.2026. Отдельные первичные анкеты не заявляются: исходный модельный набор был рассмотрен и подтверждён участниками.

## Метод распределения

- Для каждой задачи используется бинарная переменная назначения `x[i,j]` (1 — задача i назначена участнику j; 0 — не назначена).
- **Целевая функция:** максимизировать сумму предпочтений участников по назначенным задачам.
- **Ограничения:** каждая задача назначается ровно одному исполнителю; никто не превышает доступный лимит часов; каждому назначается не менее двух задач.
- **Инструмент решения:** `scipy.optimize.milp`, алгоритм HiGHS.
