**Запуск:** установить `numpy` (`python -m pip install numpy`), запустить `python phase4_monte_carlo.py` в каталоге с CSV. Скрипт повторно генерирует недельную историю, CDF и JSON.

**Контроль соответствия:** вычислительный результат повторён; отчёт Word/PDF и Excel проверены на открытие, размеры и согласование ключевых показателей. Недостающие **фактические недельные часы** остаются в [задаче #29](https://github.com/Vlad-gw/project-management/issues/29): опубликованные часы за недели *расчётно восстановлены* из дат и подтверждённых суммарных часов задач, а не взяты из первичного понедельного табеля.
