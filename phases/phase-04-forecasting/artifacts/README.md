# Артефакты Фазы 4 — Монте-Карло

**Опубликованы в ветке main:** исходные данные, воспроизводимый Python-скрипт, результаты по двум моделям в JSON и CDF в CSV. Полный разбор и таблицы — [README Фазы 4](../README.md).

| Файл | Назначение |
|---|---|
| [history_tasks.csv](history_tasks.csv) | История 31 работы из Фаз 1–3 |
| [weekly_history.csv](weekly_history.csv) | 6 недель, число завершённых задач и реконструированные часы |
| [phase5_academic_tasks.csv](phase5_academic_tasks.csv) | 12 учебных задач Фазы 5 и L/M/U |
| [phase4_monte_carlo.py](phase4_monte_carlo.py) | 2 модели, 120 000 прогонов, проверки и выходные файлы |
| [monte_carlo_results.json](monte_carlo_results.json) | P80: 4 недели и 7 недель |
| [monte_carlo_cdf.csv](monte_carlo_cdf.csv) | Распределение вероятности срока завершения |

**Запуск:** `python -m pip install numpy`, затем `python phase4_monte_carlo.py` из каталога со всеми CSV. Результаты воспроизводятся с seed 20261112.

**Методологическая оговорка:** почасовая недельная история — *реконструкция* по подтверждённым суммарным часам и диапазонам дат, а не реальный недельный табель. Прогнозные оценки учебных задач также сценарные.

**Word/PDF/Excel:** подготовлены отдельно в итоговом скачиваемом комплекте, но **их бинарные копии здесь пока не загружены**. В GitHub доступны воспроизводимые CSV, JSON, Python и развернутый отчёт в Markdown. Задача #29 остаётся открытой для подтверждения фактического недельного табеля.
