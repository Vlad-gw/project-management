## 3. Алгоритм ресурсного планирования (RCPSP)

**Цель:** минимизировать дату завершения последней работы при соблюдении порядка предшествования, длительностей и доступного числа специалистов по типам.

Используется **serial schedule generation scheme (SSGS)**:
1. Выбрать среди ещё не запланированных работ те, у которых уже запланированы все предшественники.
2. Выбрать из готовых работ одну по очередному эвристическому правилу приоритета (или случайно).
3. Разместить её на **самом раннем непрерывном интервале**, где на каждый день доступны все необходимые специалисты.
4. Повторить для остальных работ, затем проверить ограничения.

**Прерывания работ не допускаются**, деление специалиста на доли ставки не моделируется. Этот алгоритм строит допустимые решения, но **не доказывает глобальный оптимум**.

## 4. Все 12 эвристик из задания

- **SLK** — по возрастанию общего резерва `LS − ES`.
- **FREE** — по возрастанию свободного резерва `min(ES прямых последователей) − EF`.
- **LST** — по возрастанию позднего начала `LS`.
- **LFT** — по возрастанию позднего окончания `LF`.
- **LSTLFT** — по возрастанию `LS + LF`.
- **GRPW** — по убыванию `dⱼ + Σ dᵢ` прямых последователей.
- **LPT** — по убыванию длительности `dⱼ`.
- **MIS** — по убыванию числа прямых последователей.
- **GRD** — по убыванию `dⱼ × Σ rⱼₖ`.
- **GRWC** — по убыванию `Σ rⱼₖ`.
- **GCRWC** — по убыванию суммы ресурсных потребностей данной работы и её прямых последователей.
- **ROT** — по убыванию `[Σ(rⱼₖ / Rₖ)] / dⱼ`, где `Rₖ` — общедоступная численность k-го ресурса.

Сетевые ES/EF/LS/LF вычисляются **без ресурсных ограничений** — только для выбора приоритета. При равном приоритете используется идентификатор работы. При выборе каждого следующего действия сначала соблюдается готовность по FS-связям.

## 7. Проверка трудоёмкости и согласованность с Фазой 3

По WBS трудоёмкость одной работы: `dᵢ × 8 × (BAQAᵢ + BEᵢ + FEᵢ)`. Суммарно **3 400 чел.-ч**. Это на **13,98% выше** интегральной оценки **≈2 983 чел.-ч** из Фазы 3. В третьей фазе применялись укрупнённые COSMIC/UCP/экспертные оценки, здесь — конкретные сценарные длительности и занятость по дням. **Нельзя без проверки молча приравнивать две оценки**. В предзащите следует прямо отметить расхождение и необходимость согласовать исходные WBS-длительности.

Предыдущая приближённая оценка **около 29 недель** из Фазы 3 не учитывала детальный граф предшествования и дефицит конкретных специальностей. В календарно-ресурсной модели получилось **38,6 недели**; причины — зависимости, загрузка FE и BAQA и пакетные длительности неделимых работ.
