**Период:** 01.10.2026–06.10.2026  
**Выбранная концепция:** система аренды автомобилей

## Цель

Выбрать концепцию программного проекта для дальнейшей работы с помощью коллективного экспертного оценивания и двух методов многокритериального выбора.

## Альтернативы

| Код | Концепция |
|---|---|
| A1 | Система аренды автомобилей |
| A2 | Информационная система автосервиса |
| A3 | Система учёта и анализа личных финансов |
| A4 | Система управления фитнес-клубом |

## Критерии

| Код | Критерий | Тип |
|---|---|:---:|
| C1 | Практическая полезность | MAX |
| C2 | Функциональная наполненность | MAX |
| C3 | Удобство формирования Use Cases | MAX |
| C4 | Сложность реализации | MIN |
| C5 | Удобство оценки и планирования | MAX |
| C6 | Наглядность и понятность | MAX |

### Коллективный МАИ

| Место | Альтернатива | Глобальный приоритет |
|---:|---|---:|
| **1** | **A1 — Система аренды автомобилей** | **0,2976** |
