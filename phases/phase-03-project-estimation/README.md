# Фаза 3 — Оценка проекта

**Статус:** расчётная часть выполнена, модель согласована командой 02.11.2026. Закрыты 10 задач (#13–19 и #21–23); открыты #20 (подтверждение независимых экспертных оценок) и #24 (приёмка комплекта после загрузки файлов).

## Проект

**Система аренды автомобилей.** Граница: веб-интерфейс клиента и менеджера, сервер, база данных, API платёжного сервиса и уведомлений. Физическая передача автомобиля вне границы ПО.

## Состав работ

- 15 Use Cases с основными, альтернативными и негативными сценариями;
- расчёт размера по COSMIC Function Points: **108 CFP**;
- расчёт Use Case Points: **161,23 UCP**;
- коллективная экспертная оценка по каждой UC, согласованная командой;
- оценка состава команды, сроков и отложенных функций.

## Результаты согласованной оценочной модели

| Метод | Размер | Трудоёмкость |
|---|---:|---:|
| COSMIC | 108 CFP | 3024 чел.-ч (условно 28 ч/CFP) |
| Use Case Points | 161,23 UCP | 3225 чел.-ч (20 ч/UCP) |
| Экспертная медиана | 15 UC | 2655 чел.-ч (модельный набор, принят командой) |

Условное согласованное плановое значение: **около 2983 чел.-ч**. В сценарии с 4 FTE по 30 продуктивных часов в неделю это **около 29 недель с резервом 15%**. Коэффициенты и веса оценок — допущения, а не нормы COSMIC.

Возможные функции для более позднего релиза: гибкие тарифы/скидки (UC14) и расширенные отчёты (UC15), в сумме ориентировочно 355 чел.-ч по согласованной условной экспертной оценке.

## Статус и дальнейшее выполнение

**02.11.2026** команда подтвердила предложенный набор оценок, медианы, UCP-факторы и COSMIC-карту. Первичные независимые анкеты не заявляются. Коэффициенты 28 ч/CFP и 20 ч/UCP и интегральные веса 35/35/30 остаются сценарными допущениями.

Отчёт и Excel подготовлены, но **138 чел.-ч** из Фазы 2 — план работ по учебной Фазе 3, а **2 983 чел.-ч** — оценка потенциальной разработки продукта. Это разные величины; ни одна из них не означает фактически отработанное время.

Десять задач закрыты как выполненные по подготовленным учебным результатам. **Открыты #20 и #24:** нужны документальное подтверждение независимости индивидуальных экспертных оценок и окончательная проверка файлов после размещения в `artifacts/`. 138 чел.-ч — план, не фактически отработанные часы.
