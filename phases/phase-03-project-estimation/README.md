# Фаза 3 — Оценка проекта

**Статус:** расчёты выполнены и согласованы командой; итоговые файлы ожидают загрузки.  
**Проект:** система аренды автомобилей.  
**Период учёта:** 20.10.2026–03.11.2026.

## Цель

Оценить масштаб, трудоёмкость, ориентировочный срок и состав команды для создания системы аренды автомобилей с использованием нескольких методов оценки.

## Состав проекта

Границы системы: веб-интерфейсы клиента и менеджера, сервер, база данных, интеграции с оплатой и уведомлениями. Физическая выдача автомобиля находится вне границы программного обеспечения.

Разработано **15 Use Cases**: регистрация, поиск и просмотр автомобилей, проверка доступности, бронирование, расчёт стоимости, оплата, отмена и история бронирований, управление автопарком и другими функциями. Предусмотрены **основные, альтернативные и негативные сценарии**.

## Методы оценки

- **COSMIC Function Points:** функциональный размер по движениям данных `Entry / Exit / Read / Write`;
- **Use Case Points:** веса акторов, сложность Use Cases, технический и средовой коэффициенты `TCF` и `ECF`;
- **Коллективная экспертная оценка:** согласование трудозатрат по Use Cases четырьмя участниками;
- **Сопоставление методов:** обоснование итоговой плановой оценки.

## Результаты

| Метод | Результат | Трудоёмкость разработки |
|---|---:|---:|
| COSMIC | **108 CFP** | **3 024 чел.-ч** |
| Use Case Points | **161,23 UCP** | **≈3 225 чел.-ч** |
| Коллективная экспертная оценка | 15 UC | **2 655 чел.-ч** |

Интегральная плановая оценка — **около 2 983 чел.-ч**. В иллюстративном варианте с четырьмя специалистами по 30 продуктивных часов в неделю и резервом 15% срок составляет **около 29 недель**.

Для сокращения первой версии системы можно отложить **UC14 (гибкие тарифы и скидки)** и **UC15 (расширенные отчёты)** — ориентировочно 355 чел.-ч по принятой экспертной модели.

> Коэффициенты перевода CFP/UCP в часы и интегральные веса — принятые для учебной оценки предположения, а не обязательные нормативы методик.
