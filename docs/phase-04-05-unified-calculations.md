## Проверка по опубликованным результатам

- История: **31 задача**, **158 чел.-ч**.
- Monte Carlo: **120 000 итераций на модель**, `P80 = 4 / 7 недель`. Excel содержит частоты симуляций и **формулы**, пересчитывающие CDF, P80 и среднюю длительность; полный имитационный процесс воспроизводится скриптом `phase4_monte_carlo.py`.

- Проверка вычислительного движка книги: ошибок `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?` не обнаружено.
- SHA-256 локального опубликованного пользователю файла: `57de87c71bdecb30c1fab1a1e45876e41972c6a01a77828a01cfec2d45731ed7`.
